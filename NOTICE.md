# Attribution and provenance

Ghost in the Pipeline is an independently implemented Java/TPF maze inspired by **3D Maze Pro**, the MSX BASIC game maintained by antor44: https://github.com/antor44/3dmaze. That repository describes a remaster of an older game whose original author is unknown.

The upstream README and readable BASIC listing were inspected to understand behavior. No upstream source file, translated listing, drawing coordinates, music, graphics, ROM, cassette image, packaged binary, or system firmware is included here. Java rules, seeded generation, browser graphics, ghost icon, and interface were independently authored for this project. This is not an emulator, interpreter, or transpiler.

The upstream repository calls its game free and describes earlier code as abandonware; those descriptions do not establish redistribution permission. Its redistribution rights remain unresolved. This project's Apache-2.0 license applies to independently authored contributions, not to that historical material or third-party model weights. Attribution does not resolve those rights, and translating code would not by itself resolve them either. Review provenance before any public release.

TPF and other Maven dependencies retain their own licenses. Tev1 is obtained separately through Ollama and is not bundled. Consult each model's own terms. No emulator or firmware is necessary to run the modern application.
