# Sixth-sense demonstration

`sixth-sense-90s.mp4` is a real live-game recording: canvas, observed-room map, visible player/action labels and direct Web Audio output. It contains no simulated model choices. Seed 1983 is an ordinary fixed evaluation seed.

The human follows the increasing signal to the exit doorway, then resets before crossing it. Real 0.8B attempts follow with agent clues off and on; both continue proposing forward moves into a wall. The attempts are paused, rather than presented as escapes.

The first 60 seconds of raw human footage are labelled 1.5× speed; subsequent footage stays at real speed. Pitch is preserved and audio is boosted 3× for audibility. The game's conservative volume is unchanged. Final encoding is H.264/AAC, 1200×740, 20 fps, 90 seconds. Full decode, non-silent audio, and representative human/off/on frames were checked. The original capture is retained under ignored `.work/`, not published. No video recording feature was added to the application.
